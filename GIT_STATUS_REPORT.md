## Files to Exclude

### 1. Build Output Directories

| Path | Reason for Exclusion |
|------|---------------------|
| `dist/` | Contains compiled binaries generated by PyInstaller. Reproducible from source; should never be committed. |
| `release/` | Contains versioned release packages (`.exe` installers, zipped artifacts). Large binaries; managed via GitHub Releases. |
| `artifacts/` | Contains build intermediates, test outputs, and temporary files. |
| `temp/` | Build scratch directory; contents are ephemeral. |

### 2. Python Cache & Virtual Environments

| Path | Reason for Exclusion |
|------|---------------------|
| `__pycache__/` | Python bytecode cache; auto-generated, platform-specific. |
| `**/__pycache__/` | Recursive bytecode caches in all subdirectories. |
| `*.py[cod]` | Compiled Python files (`.pyc`, `.pyo`, `.pyd`). |
| `.venv/` | Virtual environment; contains system-specific paths and installed packages. |
| `venv/`, `env/` | Alternate virtual environment directory names. |
| `*.egg-info/` | Python package metadata generated during `pip install -e .`. |

### 3. Node & Frontend Build

| Path | Reason for Exclusion |
|------|---------------------|
| `node_modules/` | Node.js dependencies; thousands of files, deterministically installed via `package-lock.json`. |
| `.next/` | Next.js build output; generated from source, not reproducible if committed across platforms. |
| `*.tsbuildinfo` | TypeScript incremental build info files; machine-local. |
| `next-env.d.ts` | Auto-generated TypeScript declarations for Next.js. |

### 4. Compiled Binaries & Generated Files

| Path | Reason for Exclusion |

## Git Commands to Execute

### Stage all tracked and new source files:

```powershell
# Stage everything (respects .gitignore rules)
git add -A
```

### Review staged changes:

```powershell
# See what will be committed
git status

# Review full diff
git diff --cached --stat
```

### Create the version tag:

```powershell
git tag -a v1.3.0 -m "AICluster v1.3.0 — Project Audit & Production Readiness"
```

### Push to GitHub:

```powershell
# Push commits (if any)
git push origin main

# Push the tag separately
git push origin v1.3.0
```

### Create GitHub Release (via CLI):

```powershell
gh release create v1.3.0 release/AICluster-v1.3.0.exe release/AICluster-v1.3.0.sha256 `
  --title "AICluster v1.3.0 — Project Audit & Production Readiness" `
  --notes-file RELEASE_v1.3.0.md `
  --latest
```
