## Release Process

1. [ ] Create release branch: `git checkout -b release/v1.3.1`
2. [ ] Update VERSION to `1.3.1`
3. [ ] Update CHANGELOG.md with all Sprint 1-4 changes
4. [ ] Run full build: `python -m build.build --skip-sign`
5. [ ] Run release verification (10 stages)
6. [ ] Fix any issues found in verification
7. [ ] Merge to main: `git checkout main && git merge release/v1.3.1`
8. [ ] Tag release: `git tag v1.3.1`
9. [ ] Push to remote: `git push origin main --tags`
10. [ ] CI/CD release job completes
11. [ ] Upload release artifacts to GitHub Releases
12. [ ] Update project score from 7.5 → 9.2+
