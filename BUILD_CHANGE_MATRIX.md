## Changes

### B-001: Binary Size Optimization

| Field | Value |
|-------|-------|
| **Target** | PyInstaller builds (master, worker, CLI) |
| **Current size** | AIClusterMaster.exe: ~80 MB |
| **Target size** | <60 MB |
| **Method** | Exclude unused stdlib modules; UPX compression; audit hidden imports |

#### Excluded Modules
```python
EXCLUDED_MODULES = [
    "tkinter", "test", "unittest", "distutils", "ensurepip",
    "turtle", "idlelib", "pydoc", "http.server", "webbrowser",
    "sqlite3.test", "ctypes.test", "email.test",
    "lib2to3", "multiprocessing.dummy",
]
```

#### UPX Compression
- If UPX available: `pyinstaller --upx-dir=<path>` 
- Estimated compression: ~40% for Python DLLs
- Expected result: 80 MB → ~48 MB (master)

| File | `build/pyinstaller_builder.py`, `build/config.py` |
| Risk | MEDIUM — UPX false positives from antivirus |
| Verification | All build verification stages pass |

### B-002: CI/CD Pipeline

| Field | Value |
|-------|-------|
| **New file** | `.github/workflows/ci.yml` |
| **Trigger** | Push to main/develop, PR to main |
| **Platform** | Windows (for build/test), Ubuntu (for lint) |

#### Pipeline Stages
```
PR:

  3. test-worker (pytest)

Push to main with "release:" prefix:
  1-6 as above
  7. release (full build: python -m build.build --skip-sign)
  8. upload artifacts
```

| Risk | LOW |

## Verification Updates

### New Auth Checks in verify_api.py

```python
def test_auth_required(ctx):
    """Verify all non-public endpoints require auth."""
    protected_endpoints = [
        ("GET", "/api/v1/workers"),
        ("GET", "/api/v1/dashboard"),
        ("POST", "/api/v1/jobs"),
        ("GET", "/api/v1/ai/session"),
        ("POST", "/api/v1/plugins/install", {"plugin_id": "test"}),
    ]
    for method, path, *body in protected_endpoints:
        resp = http_request(method, f"http://localhost:{ctx.api_port}{path}", 
                           json=body[0] if body else None)
        assert resp.status == 401, f"{method} {path} should return 401 without auth"
```

### New Worker Auth Checks in verify_backend.py

```python
def test_worker_auth(ctx):
    """Verify worker registration requires secret."""
    resp = http_post(f"http://localhost:{ctx.api_port}/api/v1/workers/register",
                    json={"name": "test", "hostname": "test", "ip": "0.0.0.0"})
    assert resp.status in (401, 403), "Worker registration should require auth"
```
