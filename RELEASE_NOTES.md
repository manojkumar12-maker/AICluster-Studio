# AICluster v2.0.0 — Stable Release

**July 6, 2026**

---

## 🚀 Highlights

AICluster v2.0.0 is a major architectural update that unifies the runtime and introduces a single-click Windows installer with fully automatic first-run configuration. This release makes AICluster a true desktop platform — no Python, no Rust, no Node.js, and no manual configuration required by the end user.

### Key Changes

- **Unified Runtime**: Single `AIClusterRuntime.exe --mode master|worker|both` replaces separate `Master.exe` and `Worker.exe`
- **One-Click Installer**: Inno Setup 6 wizard installer (`AIClusterSetup-2.0.0.exe`) with automatic role configuration, firewall rules, desktop shortcuts, and uninstaller
- **Auto-Configured First Run**: Installer generates `role.json` with standalone mode; Studio auto-starts the master server on first launch
- **Improved Auth**: Login now returns full user profile (id, username, role, permissions)
- **Background Scheduler**: Job dispatch now runs automatically in the background
- **Expanded Dashboard**: 15 metrics including queue depth, active/queued jobs, and health indicators

---

## 🆕 New Features

### Desktop Experience
- Native Windows installer with modern wizard, progress bar, and optional desktop shortcut
- Studio auto-starts master server on first launch (no manual terminal or commands needed)
- `role.json` auto-generated by installer with standalone configuration
- Windows Firewall integration (optional during install)
- Tray icon with context menu (Show, Dashboard, Workers, Restart, Quit)
- Window position and size persistence

### Architecture
- **Unified runtime executable** (`AIClusterRuntime.exe`) supporting master, worker, and combined modes
- Process manager with automatic crash detection and restart (up to 5 attempts)
- Health manager with continuous monitoring of master (port 8000) and worker (port 8001)
- Lifecycle manager for startup/shutdown/recovery sequences with progress events
- LAN discovery for auto-detecting existing clusters

### Authentication
- `POST /api/v1/auth/login` now returns `user` object with full profile
- Dashboard endpoint expanded from 8 to 15 fields
- JWT validation on all authenticated endpoints
- Rate limiting (100 req/min) on login endpoint

## 🔒 Security

- JWT with HS256 algorithm, auto-generated 32-byte random secret key
- bcrypt password hashing with random salt
- CORS restricted to configured origins
- Worker authentication via JWT or shared secret
- Auto-generated admin password on first run (printed to stderr)

## 💥 Breaking Changes from v1.3.x

| v1.3.x | v2.0.0 |
|---|---|
| `AIClusterMaster.exe` (standalone) | `AIClusterRuntime.exe --mode master` |
| `AIClusterWorker.exe` (standalone) | `AIClusterRuntime.exe --mode worker` |
| `AIClusterSetup-1.3.1.exe` | `AIClusterSetup-2.0.0.exe` |
| Manual `role.json` creation required | Auto-generated by installer |
| Separate master/worker install directories | Single `runtime/` directory |
| Manual master startup | Auto-started by Studio on first launch |

## 🐛 Bug Fixes (v2.0.0)

- Fixed Tauri `build.rs` syntax error preventing Studio compilation
- Fixed frontend ID type mismatch (number → string UUID)
- Fixed `ProcessManager`/`HealthManager` state loss on Tauri commands
- Fixed `Role` enum deserialization (lowercase from frontend → PascalCase in Rust)
- Fixed worker heartbeat rejection (missing `version` field in schema)
- Fixed installer freeze (`SolidCompression=no`, `ewNoWait` for firewall)
- Fixed version numbers synced across all 6 components
- Fixed missing icon references (`cli.ico`, `studio.ico` → `default.ico`)
- Fixed scheduler autodispatch never starting
- Fixed dashboard schema mismatch with frontend

## 📋 Migration from v1.3.x

1. **Uninstall** v1.3.x completely (AIClusterMaster, AIClusterWorker, old Studio)
2. **Download** `AIClusterSetup-2.0.0.exe`
3. **Run the installer** — `role.json` is auto-generated, no manual config needed
4. **Launch Studio** — the master starts automatically
5. **Login** with `admin` / `admin` (change password immediately)

Data migration from v1.3.x is not automatic. Backup your `aicluster.db` and `config/` before upgrading.
